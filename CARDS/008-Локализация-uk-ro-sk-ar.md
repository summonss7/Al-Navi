## Задача
В `src/lib/i18n/dictionaries.ts` en и ru содержат по 370 ключей, а uk/ro/sk/ar —
по 211: 159 ключей на каждую локаль показываются английским фолбэком (меню F9
«Вид», настройки цветов/шрифта, архивы, атрибуты, мультипереименование, меню F2,
история просмотров и др. — всё, что добавлено после 1.5.x). Доперевести недостающие
ключи на украинский, румынский, словацкий и арабский (RTL), выровняв парность с en.

## Критерии готовности
- [x] В dictionaries.ts каждая из 6 локалей содержит один и тот же набор ключей (парность с en проверена скриптом/командой, вывод приложен в журнал)
- [x] Переводы смысловы, не машинная калька; для ar учтён RTL (формат с плейсхолдерами `{n}` не ломается)
- [x] `npm run check` — 0 ошибок
- [x] Ручная проверка: переключение языка в F9 показывает переведённые меню «Вид», цвета файлов, диалог Ctrl+M без английских вставок
- [x] CHANGELOG дополнен, релиз собран по конвенции (builds/ + C:\Al-Navi\Al-Navi.exe)
