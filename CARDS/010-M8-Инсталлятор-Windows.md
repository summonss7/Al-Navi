## Задача
Последний пункт первоначального мастер-плана (ROADMAP, M8). Сейчас распространение —
портативный exe из `scripts/build-release.sh`. Сделать установщик: оценить, чем
собрать без прав администратора (Inno Setup / NSIS ставятся в user-dir; WiX-msi и
кросс-сборка .deb/AppImage — отдельное решение, в этой карточке не обязательны).
Установщик должен ставить в выбор пользователем каталог (по умолчанию без UAC,
например `%LOCALAPPDATA%\Programs\Al-Navi`), создавать ярлыки (рабоч стол + меню
Пуск), деинсталлятор, иконку из src-tauri/icons.

## Критерии готовности
- [ ] Выбран инструмент и обоснование зафиксировано в журнале (что ставится без админа, размер, поддержка автоподъёма версии)
- [ ] `scripts/` содержит скрипт сборки установщика, вызываемый из релизного конвейера (или документировано, как вызывать после build-release.sh)
- [ ] Готовый setup-файл кладётся в builds/ рядом с портативным exe
- [ ] Установка на чистой машине проверена вручную: ярлыки, деинсталляция, старт, версия/время сборки в титлбаре
- [ ] README (раздел «Релизная сборка») и ROADMAP обновлены; CHANGELOG дополнен
