# scripts/archive/

Одноразовые E2E-проверки конкретных релизов (e2e-1.7.1 … e2e-1.12.0,
e2e-run-shell.cjs из 1.9.2, shot-1-10-7-dev.mjs). Каждый скрипт проверял
фиксы своей версии против собранного exe и в текущем коде воспроизводится
не обязан (моки и селекторы могли уехать вместе с интерфейсом).

Сохранены для истории и как источник приёмов (CDP, мок-бэкенд, замеры).
Не запускать вслепую: часть скриптов меняет реальный конфиг
`%APPDATA%\al-navi` и не рассчитана на сегодняшние пути.

Актуальные проверки живут уровнем выше, вход — `npm test` (см. раздел
«Проверки» в корневом README): юнит-тесты чистых функций (vitest) и
дымовой E2E по реальному exe (`scripts/e2e-smoke.mjs`), плюс тематические
наборы e2e-<тема>[-dev|-exe].mjs (архивы, атрибуты, поиск, локали,
регрессии карточек alnavi-0NN).
