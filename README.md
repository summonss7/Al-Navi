# Al-Navi

Современный двухпанельный файловый менеджер с управлением в духе FAR Manager.
Кроссплатформенный: Windows + Linux. Стек: **Tauri 2 (Rust) + Svelte 5 + TypeScript + CodeMirror 6**.

Репозиторий: <https://github.com/summonss7/Al-Navi>

Бренд (по `images/design.jpg`, `images/logo.jpg`, `images/icon.jpg`): лайм `#8EE53F` (идентичность),
оранж `#F97316` (выделение/активность), серый `#9E9E9E`, светлый интерфейс — тёплый серый фон
`#EDECEA`, белые скруглённые карточки с мягкими тенями, duotone-иконки (Phosphor), шрифт Nunito.

## Быстрый старт

### Требования

- **Node.js ≥ 20**, npm
- **Rust** (`rustup`) — <https://rustup.rs>
- Линкер:
  - **Простой путь (рекомендуется, Windows):** Visual Studio Build Tools 2022 с workload
    «Desktop development with C++» (включает MSVC + Windows SDK). Установка:
    ```
    winget install Microsoft.VisualStudio.2022.BuildTools --override "--wait --quiet --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"
    ```
    (нужны права администратора)
  - **Без прав администратора (путь, уже настроенный на этой машине):** MSYS2 + GCC:
    ```
    # MSYS2 установлен в C:\Users\CUSTOM\msys64; перед cargo добавить в PATH:
    PATH="/c/Users/CUSTOM/msys64/ucrt64/bin:$PATH"
    cargo +stable-x86_64-pc-windows-gnu build
    ```
- **Linux:** `sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget file libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev`

### Разработка

```bash
npm install

# Windows с MSVC (стандартно):
npm run tauri dev

# Windows с GNU-тулчейном (настроено на этой машине):
PATH="/c/Users/CUSTOM/msys64/ucrt64/bin:$PATH" \
  cargo +stable-x86_64-pc-windows-gnu run   # из src-tauri, при запущенном `npm run dev`

# Превью интерфейса в обычном браузере (без файловых данных, только вёрстка/темы):
npm run dev            # затем откройте http://localhost:1420

# Проверки
npm test             # всё: юнит-тесты + дымовой E2E по реальному exe (см. ниже)
npm run test:unit    # юнит-тесты чистых функций фронтенда (vitest, tests/unit/):
                     # multiRename, format (размеры/пути/маски), маски подсветки
                     # fileColors/textColors, конвертер раскладки и регистр (plugins)
npm run test:e2e     # дымовой E2E: scripts/e2e-smoke.mjs запускает реальный exe
                     # (по умолчанию C:\Al-Navi\Al-Navi.exe, свой путь: npm run
                     # test:e2e -- D:\...\Al-Navi.exe) через CDP и прогоняет ядро
                     # сценария: старт, навигация (cd, курсор, Enter/Backspace),
                     # F5-копия, F8-удаление, F4-редактор с F2-сохранением, смена
                     # темы/языка; 23 проверки, итоговая сводка и код возврата.
                     # Файловые операции идут во временной песочнице, реальный
                     # конфиг %APPDATA%\al-navi бэкапится и восстанавливается
npm run check        # svelte-check (типы)
npm run lint         # eslint (flat config, eslint.config.js): TS + Svelte + скрипты;
                     # ошибки ломают запуск, предупреждения (unused vars, each-key)
                     # не критичны
npm run format       # prettier --write . (стиль: .prettierrc, printWidth 100,
                     # prettier-plugin-svelte; исключения в .prettierignore)
node scripts/i18n-parity.mjs  # парность ключей словарей всех 6 локалей
cargo check          # из src-tauri
npm run build        # сборка фронтенда
```

Тематические E2E-наборы (по потребности, каждый против реального exe или
vite dev): `e2e-smoke` (ядро, см. выше), `e2e-archives` (M6: вход в архивы,
упаковка/распаковка), `e2e-attrs` (Ctrl+A), `e2e-search` (Alt+F7),
`e2e-i18n-locales-dev/exe` (все локали), `e2e-alnavi-023…026-…` (регрессии
конкретных фиксов; 026 — справка F1: полнота аккордов, карточки-секции,
RTL). Одноразовые проверки прошлых релизов лежат в
`scripts/archive/` (не запускать вслепую).

### Релизная сборка

```bash
npm run release
# → builds/Al-Navi-<версия>-<дата-время>.exe         — портативный exe
#   builds/Al-Navi-Setup-<версия>-<дата-время>.exe   — установщик (M8)
# + обновляет рабочую копию C:\Al-Navi\Al-Navi.exe (папка создаётся при необходимости)
```

Установщик собирается **Inno Setup** (ставится per-user, без прав администратора:
`winget install --id JRSoftware.InnoSetup --scope user`); если `ISCC.exe` не найден,
релиз ограничивается портативным exe (в консоли печатается подсказка). Установка по
умолчанию — `%LOCALAPPDATA%\Programs\Al-Navi` без UAC (в мастере можно выбрать
«для всех пользователей» — тогда Windows спросит повышение прав). Создаются ярлыки
на рабочем столе и в меню «Пуск», стандартный деинсталлятор, иконка из
`src-tauri/icons/icon.ico`, интерфейс мастера en/ru. Скрипты: `scripts/al-navi.iss`
(сценарий Inno), `scripts/build-installer.sh` (сетап из уже собранного релизного exe).

Версия берётся из `src-tauri/Cargo.toml` (`[package] version`; при изменении
синхронно обновите `version` в `src-tauri/tauri.conf.json`). Время сборки вшивается
автоматически (`build.rs` → `AL_NAVI_BUILD_TIME`) и показывается в тайтлбаре
программы рядом с версией, а также в меню F9.

При обновлении запущенный `Al-Navi.exe` закрывается принудительно (несохранённые
документы редактора будут потеряны). `C:\Al-Navi` — обычная папка без прав
администратора, UAC-запросов нет. Библиотеки не нужны: exe самодостаточен
(GNU-рантайм линкуется статически, WebView2 — компонент системы).

## Резервное копирование

Двойной клик по **`backup.bat`** (обёртка; вся логика в `backup.ps1`):

- ZIP-архив `backups/Al-Navi-backup-<дата-время>.zip` со всеми исходниками,
  конфигами и дизайн-референсами (`images/`);
- не кладутся: `.git`, `node_modules`, `dist/`, `builds/`, `backups/`,
  `src-tauri/target`, `src-tauri/gen/schemas`;
- после создания архив проверяется на читаемость;
- ротация: хранятся последние **8** архивов, старые удаляются;
- восстановление: распаковать ZIP в папку проекта.

Бэкап дополняет git: забирайте изменения в репозиторий после каждого этапа работы
(`git add -A && git commit && git push`).

|---|---|
| `Tab` | переключение активной панели |
| `←` / `→` | курсор страницей (блоком) вверх / вниз по списку; `↑`/`↓` — по строке (как в FAR) |
| `Alt+F1` / `Alt+F2` | меню дисков левой / правой панели |
| `Ctrl+F1` / `Ctrl+F2` | скрыть/показать панель |
| `Ctrl+O` / `Ctrl+P` | скрыть / показать обе панели |
| `Ctrl+U` | поменять панели местами |
| `Enter` | войти в каталог / открыть файл в ОС. При входе курсор встаёт на «..», при выходе — на строку покинутой папки (как в FAR) |
| `Shift+Enter` | открыть в Проводнике / запустить в отдельном окне Windows |
| `Ctrl+PgUp` / `Ctrl+PgDn` | уровень вверх (курсор — на покинутую папку) / войти в каталог (курсор — на «..») |
| `Ctrl+↑` | уровень вверх (откуда угодно, независимо от курсора) |
| `Backspace` | уровень вверх (при пустой командной строке) |
| `Ctrl+\` | корень диска |
| `Ctrl+R`, `Ctrl+L` | обновить панель |
| `Ctrl+.` | показать/скрыть скрытые файлы (обе панели, настройка) |
| `Insert` | выделить текущий объект |
| `Gray +` / `Gray −` / `Gray *` | выделить группу (маска) / снять / инвертировать |
| `Ctrl+F3…F7` | сортировка: имя / расширение / время / размер / без; повторное нажатие разворачивает (заголовки колонок — те же кнопки) |
| `Alt+←/→` (и `Alt+Shift+←/→`) | история каталогов назад / вперёд |
| `F3` / `F4` / `Shift+F4` | просмотр / редактор / новый файл: сразу спрашивает имя (пустое поле), создаёт файл в текущем каталоге; существующее имя — просто открывает файл |
| `Ctrl+Shift+F4` | **черновик в памяти**: текстовый документ только в RAM — набрать текст, скопировать и закрыть; на диск ничего не пишется (файл не создаётся, `Esc` закрывает без вопросов, вкладка не помечается несохранённой); повторный аккорд фокусирует открытый черновик, `F2` отказывает с подсказкой, осознанное `Shift+F2` при желании превращает черновик в настоящий файл |
| `F5` / `Shift+F5` | копировать выбранное / текущий файл (для одного файла цель может заканчиваться новым именем — копирование с переименованием; `Shift+Enter` в диалоге очищает поле и подставляет имя текущего файла — поправьте и Enter для копии/переименования на месте). Диалог открывается с выделенным текстом — ввод без установки курсора перетирает поле; `↑`/`↓` листают варианты назначения (противоположная панель, `..`, домашний каталог, `C:\temp`, корень диска + недавние цели), Enter выбирает |
| `F6` / `Shift+F6` | перенести (можно с новым именем; просто имя — переименование в текущей папке; `Shift+Enter` — как в `F5`). Перенос и переименование в пределах одного тома — мгновенные (один rename, без копирования, независимо от числа файлов); слияние с существующей папкой переносит покомпонентно — свободные имена rename'ом (mtime не трогается), конфликтующие файлы — через диалог, копируется только то, что действительно нельзя переименовать / переименовать текущий |
| `F7` | создать каталог |
| `F8` / `Shift+F8` / `Shift+Del` | удалить в корзину выбранное / файл под курсором (без пометки) / безвозвратно; если объект занят другим процессом, ошибка называет держателя — `held by: процесс (pid)` (для файлов — Restart Manager, для папок — рабочие каталоги процессов и файлы, оставшиеся после частичного удаления) |
| `Alt+F7` | **поиск файлов**: FAR-маски через запятую (`*.txt, *.md`) или regex (чекбокс), текст внутри файлов (кодировки как в редакторе, учёт регистра), диапазоны даты и размера (`10k`/`2m`/`1g` или байты), «искать папки». Результаты — в активной панели полными путями в порядке находок: `Enter` на файле — переход к месту (в каталог с курсором на файле), на папке — вход; `F3`/`F4` — открыть; `F5`/`F6`/`F8` — обычные операции по реальным путям; `..` — вернуться; `Esc` — остановить поиск (живой счётчик в футере). Параметры последнего поиска предзаполняются |
| `Alt+F5` / `Alt+F6` | упаковка / распаковка архивов: zip / tar / tar.gz / 7z; вход в архив как в папку (`Enter`), `F5`/`F6`/`F8` из архива и в архив |
| `Ctrl+M` | **мультипереименование**: маска с запятой-ИЛИ, найти/заменить, шаблоны `[N]`/`[E]`/`[C]` (имя / расширение / счётчик), живой предпросмотр старое→новое, применение через очередь операций |
| `Ctrl+A` | атрибуты файла R/O/H/S/A — три-стейт диалог (сбросить / установить / не трогать), для помеченных и под курсором |
| `F2` | пользовательское меню (`user-menu.json`): свои команды с плейсхолдерами `!!` (имя), `!` (имя без расширения), `!\` (каталог панели); Ins/F4/Del — правка |
| `Alt+F11` | история просмотров (`view-history.json`): список открытых во вьювере файлов, Enter — переоткрыть |
| `Ctrl+0…9` | перейти к сохранённому каталогу |
| `Ctrl+Shift+0…9` | назначить ярлык текущего каталога |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | кольцо окон: файл1 → файл2 → … → панели → файл1 (с одним открытым файлом — тумблер редактор ↔ панели); без документов — вкладки панелей |
| `Ctrl+T` / `Ctrl+W` | новая вкладка панели / закрыть вкладку (последнюю закрыть нельзя) |
| `Ctrl+Insert` | скопировать имена (выделенных или под курсором) в буфер |
| `Ctrl+Shift+Insert` | скопировать полные пути с именами в буфер; на «..» без пометок — полный путь текущей папки (в панели поиска — путь источника) |
| `Shift+Insert` | вставить текст в командную строку |
| `Ctrl+Enter` | дописать имя файла под курсором в командную строку (каждое следующее нажатие — имя следующего файла; удобно собирать список) |
| `F12` | список окон (панели, редакторы, вьюверы) |
| `Alt+F12` | история каталогов |
| `Alt+F8` | история команд |
| `Ctrl+E` | предыдущая команда |
| `F1` | справка по клавишам и основам |
| `F9` | настройки (вид, темы, язык, выход) |
| `F10` | выход |
| `Alt+буква` | быстрый переход по префиксу: буквы накапливаются («с», «л» → «сл»), пауза 0.9 с начинает новый поиск; работает при любой раскладке (латиница + ЙЦУКЕН) |

### Командная строка — курсор всегда в ней

Печать всегда идёт в командную строку (фокус сам возвращается после диалогов,
редактора и кликов мышью — `Ctrl+K` больше не нужен). Навигация панелей при этом
живёт рядом: `↑`/`↓` всегда двигают курсор панели; `←`/`→`, `Home`/`End`,
`Backspace` работают по панели, пока строка пуста, и редактируют строку, когда
в ней есть текст; `Enter` выполняет команду (пустая — действие по панели);
`Esc` очищает строку (пустая — сброс выделения).

Выделение текста в строке — с клавиатуры, как в любой строке ввода Windows:
`Shift+←`/`Shift+→` — по символу, `Ctrl+Shift+←`/`Ctrl+Shift+→` — по слову
(повторными нажатиями до конца/начала строки выделяется весь текст),
`Shift+Home`/`Shift+End` — до начала/конца строки одним нажатием,
`Ctrl+←`/`Ctrl+→` — переход по словам без выделения. Пока строка пуста,
стрелки с Shift работают по панели, как в FAR.

### Редактор (F4)

`F2` сохранить · `Shift+F2` сохранить как · `F7` поиск/замена · `F8` или `Ctrl+Y`
удалить строку (работает при любой раскладке — по физической клавише) · `Ctrl+PgUp`
/ `Ctrl+PgDn` курсор в самое начало / в самый конец текста (и в редакторе, и в
просмотрщике) · `F11`
плагины (смена регистра выделенного текста: как в предложении / все строчные /
ВСЕ ЗАГЛАВНЫЕ / Каждое Слово; конвертер раскладки: авто / Латиница → Кириллица /
Кириллица → Латиница — `Ghbdtn` станет `Привет`, пунктуация не трогается) ·
`Ctrl+Shift+L` конвертер раскладки в авто-режиме (работает при любой раскладке —
по физической клавише) · `Ctrl+G` перейти к строке · `Esc` закрыть.
`Ctrl+Shift+F4` — **черновик**: документ только в оперативной памяти, чтобы
набрать текст и скопировать его, ничего не сохраняя на диск (файл не создаётся,
вопроса о сохранении не возникает, позиция курсора не запоминается); работает
с панелей, из редактора и из вьювера, повторное нажатие возвращается к уже
открытому черновику.
`Ctrl+Tab` — свернуть редактор на панели и ходить по открытым файлам кольцом,
документы остаются в памяти; вкладки открытых файлов над текстом (`●` —
несохранён, `×` — закрыть). Строка-курсор подсвечена как в панелях, выделение
текста — оранжевое, у каждой роли синтаксиса свой цвет. **Позиция курсора и
прокрутка запоминаются для каждого файла** — при переключении вкладок, возврате
из панелей и даже после перезапуска программы (закрытие крестиком тоже
сохраняет); вьювер F3 помнит прокрутку и страницу hex так же.

Нижний статус-бар показывает строку/колонку курсора, размер выделения, а также
**символ под курсором с его кодом** (десятичным и шестнадцатеричным: `'A' 65
0x41`; для не-ASCII — код Unicode, например `'П' 1055 0x41F`; переводы строк и
табуляция отображаются как `\n` / `\t`) и **итоги по документу** — всего
символов, строк и пробелов (суррогатная пара считается одним символом). Итоги
пересчитываются на лету при вводе; у гигантских файлов — с короткой паузой,
чтобы не тормозить печать.

**Удерживайте Ctrl / Alt / Shift** — нижняя панель F-клавиш на время подсказок
меняется на список аккордов с этим модификатором в текущем режиме (как в FAR;
в редакторе и вьювере — только Ctrl); чипы кликабельны. Та же подсказка —
внизу справки F1.

Кодировки: UTF-8, UTF-16LE/BE, Windows-1251, KOI8-R, CP866, ISO-8859-5 — автодетект при
открытии, выбор кодировки и типа концов строк (LF/CRLF) в статус-баре.

Даты и цепочки спецсимволов подсвечиваются цветом: `2024-01-31`, `31.01.2024 10:30`,
`10:30:45`, а также `===`, `---`, `###`, `>>>` (3+ спецсимвола подряд). Работает в
любых файлах, включая `.txt`; отключается в F9 → «Редактор».

### Настройки (F9)

Вид (папки вверху, скрытые/системные файлы), цвета файлов по маскам, **размер
шрифта** (степпер −/+, 10–24 px — масштабируется весь интерфейс, число строк
панелей пересчитывается), **цвета подсветки** (пикеры «Выделение» — оранжевая
семья: курсор/выделение/маркер/рамка активной панели; «Фирменный цвет» — лайм:
лого/вкладки/кнопки; «Сбросить» возвращает тему), тема (5 тем + авто), язык
интерфейса. Всё хранится в `%APPDATA%/al-navi/settings.json`.

### Вьювер (F3)

Текст · Hex (`F8` переключение) · изображения. В текстовом режиме клавиатура
принадлежит тексту: `↑/↓` — по строке, `PgUp`/`PgDn` — постранично,
`Ctrl+PgUp`/`Ctrl+PgDn` — в самое начало / конец документа, `Home`/`End` — по
строке; колесо мыши скроллит как обычно. Позиция (строка-курсор и прокрутка)
запоминается для каждого файла — при переоткрытии и после перезапуска.

---

## Возможности

- ✅ Две панели, вкладки панелей (`Ctrl+T`/`Ctrl+W`), виртуальный список (100 000+ файлов)
- ✅ Хлебные крошки в шапке панели (клик по сегменту — переход)
- ✅ FAR-навигация стрелками: `↑/↓` — по строке (с заворотом), `←/→` — блоком на область видимости
- ✅ Клавиатурная навигация во всех списках-диалогах: диски (`Alt+F1`/`Alt+F2`), окна (`F12`), истории (`Alt+F12`, `Alt+F8`)
- ✅ Файловые операции с прогрессом, скоростью, паузой/отменой, фоновым режимом
- ✅ Разрешение конфликтов: перезаписать / пропустить / переименовать (+ «для всех»)
- ✅ Корзина (`trash`) и безвозвратное удаление
- ✅ FTP: `Alt+F1`/`Alt+F2` → FTP — быстрое соединение и сохранённые сайты; навигация,
  просмотр (`F3`, текст/hex), правка с сохранением на сервер (`F4`/`F2`), `F7` — каталог;
  автопереподключение после обрыва/перезапуска
- ✅ Клавиши быстрого перехода на FTP: в меню дисков цифра `2` открывает список FTP
  (клавиша показана на строке FTP); каждому сайту в форме назначается буква или
  цифра — нажатие в списке FTP сразу подключает (по физической клавише — работает
  и в русской раскладке)
- ✅ FTP-операции: `F5`/`F6` — RETR/STOR с прогрессом в обе стороны (FTP↔диск,
  FTP↔FTP; каталоги рекурсивно, mtime сохраняется; перенос в пределах одного
  сервера — мгновенный RNFR/RNTO), `F8` — DELE/RMD, `Shift+F6` — переименование;
  та же очередь операций: пауза/отмена/фон, конфликты перезаписи; трансферы идут
  по собственным соединениям — панели не блокируются
- ✅ `ftp://user@host:port/dir` в командной строке подключает панель (FAR-style)
- ✅ Плагины `F11` в редакторе: смена регистра (4 режима) и конвертер раскладки выделенного текста (`Ghbdtn` ↔ `Привет`; `Ctrl+Shift+L` — авто-режим; `Ctrl+Z` работает)
- ✅ `Ctrl+буквы` при любой раскладке клавиатуры (аккорды по физической клавише)
- ✅ Цвета файлов по маскам + «жирный» (F9 → Цвета файлов)
- ✅ Настройка размера шрифта (F9, степпер −/+) — масштаб всего интерфейса
- ✅ Настройка цветов подсветки интерфейса (F9, пикеры выделения и фирменного цвета)
- ✅ Редактор с подсветкой 30+ языков, подсветка дат и цепочек спецсимволов,
  мультидокументы, `Ctrl+Tab`
- ✅ Вьювер: текст / hex / изображения
- ✅ 5 тем (Al-Navi Dark/Light, Midnight, Solarized, High Contrast) + авто по системе;
  **Al-Navi Light** (по `images/design.jpg`) — тема по умолчанию
- ✅ 6 языков интерфейса: English, Русский, Українська, Română, Slovenčina, العربية (RTL)
- ✅ Ярлыки каталогов Ctrl+0…9, история каталогов и команд
- ✅ Командная строка внизу с историей и `cd` (фокус при старте, `Esc` — вернуть фокус панелям)
- ✅ Наблюдение за ФС (автообновление панелей)
- ✅ Сохранение состояния (панели, ярлыки, история) в `%APPDATA%/al-navi` / `~/.config/al-navi`
- ✅ Превью интерфейса в обычном браузере без бэкенда (`npm run dev` → http://localhost:1420)
- ✅ Поиск файлов Alt+F7 (маски/regex, текст внутри файлов с кодировками,
  дата/размер, отмена по Esc, результаты в виртуальной панели)
- ✅ Редактор/вьювер помнят позицию курсора и прокрутку (в сессии и между
  запусками)
- ✅ Архивы (1.9.0): вход в zip/tar/tar.gz/7z как в папку, `Alt+F5`/`Alt+F6`
  упаковка/распаковка, `F5`/`F6`/`F8` из архива и в архив
- ✅ Атрибуты `Ctrl+A` (R/O/H/S/A, три-стейт диалог) — 1.9.1;
  мультипереименование `Ctrl+M`, пользовательское меню `F2`,
  история просмотров `Alt+F11` — 1.10.0; фикс `Ctrl+Shift+Ins` на «..» — 1.10.1;
  фикс: ошибка удаления занятого файла/папки называет процесс-держатель — 1.10.2;
  фикс списка целей F5/F6 — 1.10.3; фикс курсора при входе в папку — 1.10.4;
  клавиши перехода на FTP — 1.11.0; фикс: окно, закрытое свёрнутым, больше не
  запоминает «полосочку» 181×24 — 1.11.1
- 🚧 Дальнейшее — инсталляторы (M8) и V2 (SFTP, сравнение папок, терминал,
  плагины); оперативный план работ — карточками в `CARDS/`, полный список

## Структура

```
src-tauri/src/     Rust-бэкенд: fs (листинг/диски/открытие), ops (копирование/перемещение/
                  удаление с прогрессом и конфликтами), textio (кодировки, hex),
                  search (Alt+F7: walkdir + пул потоков, события search:hit/done),
                  ftp (сессии FTP: соединение, листинг MLSD/LIST, чтение/запись),
                  ftp_ops (FTP-трансферы RETR/STOR, DELE/RMD, RNFR/RNTO в очереди ops),
                  watch (notify-debouncer), config (JSON-хранилище), drives (sysinfo)
src/lib/           Ядро: keymap (FAR-карта клавиш), commands (реестр команд), api (IPC),
                  stores (panels/ops/editor/settings/i18n/cmdline/ui/ftpSites),
                  ftp.ts (пути ftp://), plugins.ts (F11), editor/cm.ts (CodeMirror)
src/components/    TitleBar, PanelsGrid, FilePanel, VirtualList, CmdLine, FKeyBar,
                  Dialogs, EditorArea, ViewerArea
scripts/           make-icon.mjs (генерация бренд-иконки), build-release.sh (релиз в builds/:
                  портативный exe + сетап), build-installer.sh + al-navi.iss (установщик Inno
                  Setup), e2e-smoke.mjs (дымовой E2E для npm test) и тематические
                  e2e-<тема>[-dev|-exe].mjs (CDP / vite dev), i18n-*.mjs (локали),
                  winstate-clamp-test.rs (Rust-логика standalone rustc),
                  archive/ (одноразовые проверки прошлых релизов)
images/            дизайн-референсы: design.jpg (макет), logo.jpg, icon.jpg, font.jpg, color.jpg
backup.bat/.ps1    резервные копии проекта в backups/ (ротация 8 архивов)
CHANGELOG.md       история версий
```

(таблица «контекст → сочетание → команда»; контексты: panel, editor, viewer, dialog, cmdline).
