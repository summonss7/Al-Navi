## Задача
`npm run build` даёт один JS-чанк 1.29 MB (gzip 438 KB) — vite предупреждает.
Основной вес — языковые пакеты CodeMirror (30+ языков) и шрифты подключаются
сразу. Динамически импортировать тяжёлые редкие части (языки подсветки, кроме
пары ходовых, загружать при первом открытии соответствующего файла в
редакторе/вьювере), при необходимости manualChunks в vite.config.ts.

## Критерии готовности
- [ ] Основной (стартовый) JS-чанк < 500 KB после минификации — цифра до/после в журнале
- [ ] Языки подсветки подгружаются лениво: первый запуск редактора с .rs/.py/… файлом подтягивает язык без заметной паузы и без ошибок консоли
- [ ] Прогресс-индикация/отсутствие мигания при первой загрузке языка проверено вручную
- [ ] `npm run check` — 0 ошибок, `npm run build` без предупреждений о размере чанка
- [ ] Дымовой E2E (старт, редактор с подсветкой, вьювер) на реальном exe зелёный; CHANGELOG дополнен
